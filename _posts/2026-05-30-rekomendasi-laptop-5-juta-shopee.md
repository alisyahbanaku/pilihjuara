Range Rp 5 jutaan adalah sweet spot laptop buat mahasiswa dan pekerja remote di 2026. Performance-nya cukup untuk Office, browsing multi-tab, video call, dan multimedia. Saya breakdown 5 laptop terbaik di range ini berdasarkan real-world use, bukan benchmark sintetis.

## Kriteria Comparison

- **Processor**: minimum Ryzen 5 5500U / Intel Core i3-1215U
- **RAM**: 8GB minimum, 16GB lebih ideal
- **Storage**: 512GB SSD NVMe
- **Display**: minimum 14" FHD IPS
- **Battery**: minimum 6 jam real-world
- **Build**: chassis tidak terlalu fleksibel, hinge kuat

## 1. Acer Aspire 5 (2024) — ⭐ 4.6/5 (overall winner)

**Range harga:** Rp 5.0-5.7 juta (Ryzen 5 5500U / 8GB / 512GB)

**Plus:**
- Build aluminum top, plastic body — lighter dari kompetitor di range sama
- Display 14" IPS FHD dengan thin bezel
- Keyboard backlight (rare di range ini)
- Port lengkap: USB-C, HDMI, USB-A x2, SD card reader
- Battery 8-10 jam real-world untuk Office work

**Minus:**
- Speaker mediocre, butuh earphone untuk pengalaman musik decent
- Webcam HD biasa, low-light kurang
- Touchpad bisa lebih precise

Best buy overall. Acer punya service center di hampir semua kota besar Indonesia, after-sales solid.

## 2. Lenovo IdeaPad Slim 3 — ⭐ 4.4/5

**Range harga:** Rp 4.8-5.5 juta (Ryzen 5 7520U / 8GB / 512GB)

**Plus:**
- Chipset Ryzen seri 7000 = lebih hemat baterai dan responsive
- Build solid, hinge kuat
- Keyboard Lenovo terkenal nyaman untuk typing panjang
- Update Windows 11 lancar sampai bertahun-tahun

**Minus:**
- Display TN panel di varian termurah — pilih varian IPS
- USB-C tidak support charging
- Bezel bawah masih cukup tebal

Pilih kalau kamu prioritas keyboard quality (typist berat) dan brand Lenovo familiar.

## 3. ASUS Vivobook 14 — ⭐ 4.2/5

**Range harga:** Rp 5.2-5.9 juta (Ryzen 5 7530U / 16GB / 512GB)

**Plus:**
- RAM 16GB di range ini = unusual, future-proof
- Display IPS NumberPad (touchpad jadi numpad — useful untuk akuntansi)
- ErgoLift hinge — angle keyboard saat dibuka, comfort typing
- Lid 180° flat — flexible untuk presentasi

**Minus:**
- Berat 1.5kg — di atas average kelas thin-and-light
- Charger barel (bukan USB-C)
- Build plastic feels cheap di edge

Best buy kalau prioritas multitasking heavy (banyak browser tab + Office + Slack).

## 4. HP 14s — ⭐ 3.9/5

**Range harga:** Rp 4.5-5.2 juta (Ryzen 3 7320U / 8GB / 512GB)

**Plus:**
- Brand HP after-sales luas di Indonesia
- Build cukup ringan (1.4kg)
- Keyboard nyaman, full-size dengan numpad di varian 15"

**Minus:**
- Ryzen 3 di range ini sebenarnya kurang competitive — cek varian Ryzen 5 jika ada
- Display TN di banyak varian — pastikan pilih yang IPS
- Speaker kecil, audio output flat

Pilih kalau kamu udah punya bias ke ekosistem HP atau dapat diskon besar di event seperti 9.9, 11.11.

## 5. AXIOO Mybook 14H — ⭐ 3.5/5 (skip kecuali budget tight banget)

**Range harga:** Rp 3.8-4.5 juta (Ryzen 3 5300U / 8GB / 256GB)

**Plus:**
- Brand lokal Indonesia, warranty domestic
- Termurah di list
- Build ringan (1.3kg)

**Minus:**
- Ryzen 3 + 8GB = tight untuk multitasking
- Display TN panel — viewing angle terbatas
- Build feels cheaper than competitor
- Resale value rendah karena brand awareness terbatas

Pilih hanya kalau budget mentok di Rp 4 jutaan dan butuh laptop sekarang. Kalau bisa nabung 1-2 bulan lagi untuk masuk Acer Aspire 5, lakukan.
