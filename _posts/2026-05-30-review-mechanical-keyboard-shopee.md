Mechanical keyboard sudah jauh lebih affordable di 2026. Di range Rp 300-600rb, kamu bisa dapet build quality solid dengan hot-swappable PCB dan RGB lighting. Saya review 5 pilihan terbaik untuk coder, gamer, dan WFH professional.

## Kriteria Testing

- **Long typing session**: 4-6 jam coding/writing per hari, 1 minggu
- **Build quality**: case rigidity, weight, finish
- **Switch feel**: konsistensi feel antar tombol, bottom-out feel
- **Software**: customization layer, macro, RGB control

## 1. Keychron K2 V2 — ⭐ 4.7/5 (overall winner)

**Range harga:** Rp 550-700rb (varian non-RGB) / Rp 750-900rb (RGB)

**Plus:**
- Layout 75% — full function row, kompak tapi tetap productive
- Hot-swappable di varian Pro (V2 versi terbaru)
- Build aluminum frame — solid, gak ada flex
- Wireless Bluetooth + USB-C wired (dual mode)
- Mac-friendly key cap (universal untuk Windows/Mac)
- Software Keychron VIA support

**Minus:**
- Versi non-RGB warm white only (no color variation)
- Battery wireless mode 240 jam (off RGB) tapi cuma 30-40 jam dengan RGB on
- Harga di varian top sudah masuk Rp 1 jutaan

Best buy overall untuk WFH professional yang mix-use Mac/Windows. Build dan switch quality consistent.

## 2. Royal Kludge RK68 / RK Royal Kludge — ⭐ 4.4/5

**Range harga:** Rp 350-500rb

**Plus:**
- Hot-swappable PCB
- Layout 65% (no function row, kompak banget)
- Triple connectivity: USB-C wired + Bluetooth + 2.4GHz wireless dongle
- RGB lighting
- Switch options luas (Red, Blue, Brown bawaan)

**Minus:**
- Build mostly plastic
- Software RK customization terbatas (no VIA support)
- Bluetooth latency lebih tinggi dari Keychron
- Stabilizer dari pabrik agak rattle (perlu lube untuk best feel)

Best value untuk coder yang OK dengan layout 65%. Hot-swappable berarti kamu bisa upgrade switch nanti tanpa beli keyboard baru.

## 3. Aula F75 / Aula F87 — ⭐ 4.3/5

**Range harga:** Rp 400-550rb

**Plus:**
- Layout 75% (F75) atau TKL (F87)
- Hot-swappable, gasket-mounted (rare di range ini)
- Sound dampening foam built-in — typing sound lebih clean
- South-facing RGB
- Switch HMX atau TTC tier (lebih premium dari Outemu)

**Minus:**
- Brand Aula kurang dikenal di Indonesia, after-sales terbatas
- Software AulaWebsite kurang polished
- Stock di Shopee Indonesia kadang lambat refill

Underrated pick. Kalau kamu OK dengan brand non-mainstream, sound profile dan typing feel-nya bagus banget di harga ini.

## 4. Rexus Daxa M71 — ⭐ 4.0/5

**Range harga:** Rp 380-490rb

**Plus:**
- Brand established di Indonesia (Rexus) — after-sales mudah
- Hot-swappable
- RGB lighting bagus, software Rexus stabil
- Layout 75%
- Switch options luas (Outemu Red, Blue, Brown)

**Minus:**
- Build plastic, weight ringan = ada flex saat ditekan keras
- Switch Outemu durability average (lebih cepat aus dari HMX/Gateron)
- USB-C cable bawaan kualitas biasa, perlu replace

Pilih kalau kamu prioritas after-sales lokal dan brand familiar. Untuk pure performance per rupiah, ada opsi lebih baik.

## 5. Vortex Series (no-brand variant) — ⭐ 3.4/5 (skip kecuali untuk eksperimen)

**Range harga:** Rp 200-300rb

Banyak listing keyboard mechanical di range ini dengan label generic seperti "Vortex Mechanical RGB". Saya test 1 unit:

**Plus:**
- Termurah masuk mechanical keyboard
- RGB lighting (basic)

**Minus:**
- Switch Outemu yang sudah aus dari pabrik (consistency rendah)
- Build flexy — case ditekan agak menekuk
- Stabilizer rattle parah, butuh manual mod
- Tidak hot-swappable
- USB-C non-detachable
- Software bermasalah, RGB kontrol kasar

Skip kecuali kamu beli sebagai project DIY untuk modding (lubing, foam mod, switch swap) — total budget bisa naik sama dengan beli RK68 ready-to-go.

## Switch Recommendation Singkat

- **Coder**: Brown atau Tactile (Cherry MX Brown clone, Outemu Brown, Akko Lavender)
- **Gaming kompetitif**: Red (linear, smooth, fast actuation)
- **Typist (writer, jurnalis)**: Blue (clicky) — tapi only kalau kerja di ruang sendiri (berisik)
- **Mixed use**: Brown (middle ground)

## Tips Beli Mechanical Keyboard di Shopee

1. **Filter Shopee Mall** atau pilih seller dengan rating 4.8+
2. **Pastikan switch tipe yang benar** — banyak listing salah label switch type
3. **Cek hot-swappable** kalau kamu mau upgrade nanti
4. **Tanya seller**: tahun produksi (untuk Royal Kludge, batch 2024+ lebih konsisten)
5. **Pilih COD untuk transaksi >Rp 500rb** — bisa cek typing feel sebelum bayar
6. **Beli case dan deskmat bareng** — total harga bisa lebih hemat dengan bundle deal

## Aksesoris Wajib (Optional)

Setelah punya mechanical keyboard, biasanya butuh:
- **Wrist rest** — Rp 50-150rb, kurangi RSI di pergelangan
- **Deskmat 80x40cm** — Rp 100-200rb, dampen sound + protect desk
- **Switch tester** (kalau hot-swappable) — Rp 100-200rb, eksperimen sebelum commit beli switch banyak

Total budget komplit untuk masuk hobi mechanical keyboard: **Rp 700rb - 1 juta** (keyboard + accessories). Setelah itu, hobi ini bisa expand jauh tergantung deep dive ke modding, custom builds, dll.
